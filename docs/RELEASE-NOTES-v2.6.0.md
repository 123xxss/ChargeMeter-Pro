# 瓦镜 Pro 2.6.0

## OPPO / vivo / 小米适配

同一个 APK 自动识别品牌，功能一致，无需安装三个不同包名版本。

- OPPO（ColorOS / OxygenOS / realme UI）、vivo（OriginOS / Funtouch）、iQOO、小米（MIUI / HyperOS / Redmi / POCO）默认 2 芯；
- 电流 µA/mA 自动兼容，避免部分 ROM 功率少 1000 倍；
- 整包电压上报自动按电芯数还原，避免被判“不可用”；
- 品牌后台白名单路径更新到 ColorOS/OriginOS/HyperOS 现代路径；
- 设置 → 关于新增品牌/ROM/默认电芯数适配摘要；详细矩阵见 `docs/COMPATIBILITY.md`。
