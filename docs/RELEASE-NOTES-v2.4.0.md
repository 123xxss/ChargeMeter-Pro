# 瓦镜 Pro 2.4.0

## 状态栏开关

- 主界面右上角新增铃铛开关；设置中的「状态栏通知」同步。
- 关闭：停止前台通知服务并取消通知（Android 前台服务必须有通知，不能只隐藏通知）。
- 开启：在可见界面恢复服务；主开关关闭时不启动。

## 图标与动画

- 通知栏小图标改为镜头环+闪电单色图标，与 App 图标一致；
- 通知大图标使用新 App 图标，强调色统一；
- 充电中状态栏显示本轮充电计时器（自动走秒）和电量进度；
- 静止状态不显示时间戳，减少刷新闪烁。
