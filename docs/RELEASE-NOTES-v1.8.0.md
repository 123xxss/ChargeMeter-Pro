# ChargeMeter Pro 1.8.0

## UI

- **5 种风格**：Apple 极简（默认）、经典渐变、深色霓虹、薄荷清透、紫色星云；功率卡和曲线同步切换。
- 页面进入/退出淡入滑动；主界面卡片错峰入场；设置二级页淡入；详情弹窗缩放淡入。
- 修复详情弹窗进入动画尺寸跳变，以及高度超出屏幕/滚动不完整。
- 详情与关于页新增设备信息：厂商、品牌、型号、设备代号、Android 版本、ROM 版本、ABI。

## 系统状态 / Shizuku

- CPU、GPU、系统温度直接读取失败时，可使用 Shizuku 只读 UserService 的 `readSystem()` 兜底。
- 主界面系统状态卡与详情弹窗均提供「用 Shizuku 尝试读取」入口。
- 未安装、未授权、不可读时保持 `--`，不伪造数据。

## 适配说明

- 通用 Android（11–16）。
- 不包含 iOS / 苹果设备（无法安装 Android APK）。
- 华为/荣耀私有快充协议不做专门适配，仍可安装，功率可用校准修正。
