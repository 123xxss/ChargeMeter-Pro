# 真机验收清单（vivo / OPPO / 小米）

> 本清单对应 PRD 8.4 / 8.5。当前自动化测试已覆盖算法与静态安全，但真机项需安装 APK 后逐项确认。

## 通用

- [ ] 安装后首次打开：通知权限请求出现；授予后通知栏出现低优先级「充电功率监测中」。
- [ ] 首次打开弹出当前品牌后台白名单引导；「去设置」能跳到对应页面或应用详情页。
- [ ] 未充电：主界面不显示功率数字；电压/电流指标为 `--`；通知不出现功率。
- [ ] 插入充电器 1 秒内：锁屏/通知显示功率、档位、电量、温度、预估；主界面同步。
- [ ] 拔出充电器：功率显示立即隐藏；通知回到待机，不残留旧数值。
- [ ] 充满：显示「已充满」，不再显示功率数字；通知不显示 `0.0 W`。
- [ ] 深色/浅色切换、横竖屏/折叠屏：无遮挡、无错位。
- [ ] 详情弹窗：电压/电流/温度/平滑峰值/剩余时间/数据来源齐全；固定口径说明可见。
- [ ] 设置总开关关闭：主界面隐藏全部功率卡片；通知消失；重新开启后恢复。
- [ ] 通知权限撤销：主界面出现横幅；锁屏/主界面仍可用；重新授权后横幅消失。

## vivo / iQOO

- [ ] 充电中 `current_now` 为负值时，显示功率为正（不出现负瓦数）。
- [ ] 拔电后立即隐藏，不出现冻结的旧数值。
- [ ] 双电芯高功率机型：67W/80W 档位显示接近标称（考虑效率损耗），不是一半。
- [ ] 按引导设置后台高耗电/电池优化后，锁屏亮灭循环仍持续刷新。

## OPPO / 一加 / realme

- [ ] 双电芯机型与外部功率计对比：扣除效率后误差在合理范围，不出现系统性一半。
- [ ] 详情弹窗不出现「实时充电器输入功率」；不把协商上限当实时值。
- [ ] ColorOS 应用耗电管理设为「完全允许后台行为」后，切后台不冻结。
- [ ] 单电芯 30W 左右机型如果显示翻倍，设置 → 双电芯修正 → 关闭后应恢复正确。

## 小米 / Redmi / POCO

- [ ] ≥50W 充电器下功率不是单电芯水平（自动修正生效，或 POWER_MAX 广播被识别）。
- [ ] 充满预估不是数小时历史均值（本实现不使用系统 API，预估应在合理范围）。
- [ ] 应用智能省电设为「无限制」并关闭神隐模式限制后，锁屏持续刷新。
- [ ] 若系统广播 `POWER_MAX` 不可用，高功率双电芯应仍能按品牌/电流启发式修正。

## 实时功耗检测

- [ ] 开启子开关后，充电中净功耗取绝对值，与充电功率口径不矛盾。
- [ ] 充电中净电流接近零：显示「接近零/电池放电中」，不显示误导性的 `0.0 W`。
- [ ] 拔电后：显示「放电功耗 XX W」，随亮屏/负载合理波动，不跳变、不冻结。
- [ ] 关闭子开关后：回到入电池功率口径，拔电隐藏充电功率。

## 记录方式

记录：机型、ROM 版本、充电器/线材、系统显示功率、App 显示功率、外部功率计（如有）、是否按引导设置后台白名单。功率对比时注明「入电池功率」与「充电器输入功率」的差异，不要把充电器标称值当基准。
