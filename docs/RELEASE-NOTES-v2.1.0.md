# 瓦镜 Pro 2.1.0（WattLens Pro）

## 新增：应用耗电排行

- 主页新增「应用耗电排行」入口。
- 独立页面列出最近 24 小时应用/系统应用的前台使用时长、前台占比和估算耗电。
- 每 2 秒自动刷新，带应用图标和前 30 名列表。
- 可选「使用情况访问」权限：只读前台使用时长，不读聊天内容、不联网。
- 页面明确标注：Android 不开放精确每应用 BatteryStats，排行是“前台时长 + 电池功率占比”的估算，不代表后台真实耗电。

## 说明

- 没充电、没开实时功耗时也能打开排行，耗电估值显示 `--`，但前台时长排行仍可用。
- 系统应用会标记 `系统`；所有数据只在本机计算。
