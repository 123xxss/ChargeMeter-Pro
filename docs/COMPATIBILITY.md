# OPPO / vivo / 小米 适配说明

同一个 APK 运行在 OPPO（含一加/realme）、vivo（含 iQOO）、小米（含 Redmi/POCO）上，功能一致；无需三个不同包名，避免用户装错版本。

## 适配矩阵

| 品牌 / ROM | 推荐电芯数 | 电流单位兼容 | 整包电压兼容 | 后台引导 |
|---|---|---|---|---|
| OPPO / ColorOS、OnePlus / OxygenOS、realme UI | 2 | 支持 µA / mA 自动兜底 | 支持整包电压按 2 芯还原 | 电池 → 应用耗电管理 / 自启动 |
| vivo / OriginOS、iQOO / Funtouch OS | 2 | 支持 µA / mA 自动兜底 | 支持整包电压按 2 芯还原 | 电池 → 后台耗电管理 / 自启动 |
| 小米 / HyperOS、Redmi、POCO | 2 | 支持 µA / mA 自动兜底 | 支持整包电压按 2 芯还原 | 应用管理 → 省电策略 / 自启动 |

## 已验证/处理

- Android 11–16 通用；Android 16 edge-to-edge、状态栏/通知权限、前台服务限制已处理。
- 负电流符号统一取绝对值计算功率；电流接近零显示不可用/接近零，不输出误导值。
- 单电芯异常机型可用设置 → 电芯数手动改为 1。
- 通知使用低优先级渠道、独立新 channel、大小图标与 App 图标统一。
- 状态栏关闭会停止前台通知服务；重新开启需从可见界面恢复。
- 使用情况访问/精准模式：ColorOS/OriginOS/HyperOS 的设置路径可能不同，应用会回退系统设置/应用详情。
- Shizuku 系统状态读取在标准接口不可用时作为只读兜底；失败不伪造。

## 边界

- 精确每应用耗电仍需系统 BatteryStats；普通安装不可得。应用排行是估算；精准模式是约 30 秒的系统估算。
- 华为/荣耀私有快充协议不做专门适配；Apple 设备无法安装 Android APK。
