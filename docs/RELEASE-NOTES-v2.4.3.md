# 瓦镜 Pro 2.4.3

## 真正原因

- 通知代码已经指向 `ic_notify_lens`，但图标生成脚本只更新了 `ic_notify.png`；
  `ic_notify_lens.png` 一直保留旧闪电文件，所以状态栏图标一直没变。
- 已同步所有密度的小图标，并重新生成大图标。

## 修复

- 新小图标：加粗镜头环 + 闪电，更深、更容易辨认。
- 通知强调色改为新版深青 `#004B5A`，不再是浅蓝色背景感。
- channel 改为 `charge_monitor_v4`，通知 ID 改为 `0x504F`。
- App 启动、服务启动时清理旧 channel/旧通知；设置 → 后台运行 → 重置状态栏通知可用。
- 通知大图标使用瓦镜新图标。

## 如果仍显示旧图标

1. 设置 → 关于确认是 2.4.3；
2. 重置状态栏通知；
3. 仍不生效：卸载旧版后重装，或重启手机（厂商缓存）。
Android 状态栏小图标是单色剪影，不能与彩色 App 图标完全一样；展开通知的大图标才是完整彩色图标。
