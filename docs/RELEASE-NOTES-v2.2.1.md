# 瓦镜 Pro 2.2.1

## 修复应用排行“假数据”

- 旧版使用 24 小时 UsageStats 聚合，会列出很久以前打开、当前不在前台的软件。
- 新版改用 UsageEvents，只统计最近 **5 分钟**真正进入前台的应用。
- 切到瓦镜 Pro 时结束上一个应用的前台区间，不再把已经离开的应用继续计入。
- 主界面 Top 3 每 3 秒刷新；完整页每 2 秒刷新。

## 边界

- Android 不向普通第三方开放精确 BatteryStats；耗电仍是“前台时长占比 × 电池功率”的估算。
- 后台真实耗电无法通过公开 API 获取；页面会明确标注，不伪造。
