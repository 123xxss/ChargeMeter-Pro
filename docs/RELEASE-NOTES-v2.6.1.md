# 瓦镜 Pro 2.6.1

## 双电芯电压展示

- 主界面实时数据：`总压 / 单芯`，例如 `8.25 / 4.13`，标签「总压 / 单芯 (V)」。
- 详情页拆成「总电压」「单芯电压」两行。
- 兼容两种上报：
  - 系统上报单芯电压：总压 = 单芯 × 电芯数；
  - 系统上报整包电压：单芯 = 整包 ÷ 电芯数。
- 单电芯机型仍显示一个电压值。
- 功率仍用整包电压 × 电流，单芯电压只展示，不重复乘电芯数。
