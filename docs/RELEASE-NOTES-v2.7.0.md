# 瓦镜 Pro 2.7.0

## 双芯 / 单芯自动识别

- voltage_max ≥ 6V → 双芯；
- 整包电压 > 5V → 双芯；
- 已知双电芯机型优先于 3–5V 的 voltage_max 提示；
- voltage_max 3–5V → 单芯；
- 无特征时按品牌默认，并明确标注“低置信度，可手动覆盖”。

## 电压显示

- 双芯：主界面 `总压 / 单芯`，详情拆成「总电压」「单芯电压」；
- 单芯：只显示单芯电压，不会多乘 2；
- 功率始终按整包电压 × 电流，单芯电压只展示。

## 界面解释

- 主界面实时数据卡底部显示「电芯：自动 · 判定依据」；
- 点击可查看完整识别规则；
- 详情页显示「电芯判定」；
- 设置 → 电芯数仍可手动覆盖。
