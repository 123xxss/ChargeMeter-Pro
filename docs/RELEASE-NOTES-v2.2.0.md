# 瓦镜 Pro 2.2.0（WattLens Pro）

## 主界面应用排行

- 主界面直接显示应用耗电排行 Top 3：图标、名称、估算功率/前台占比。
- 每 3 秒刷新；点「查看全部」进入完整排行页。
- 完整页每 2 秒刷新，前 30 名，含系统应用标记。
- 未授权「使用情况访问」时，主界面显示授权提示；授权后自动出现排行。

## 边界说明

- Android 不开放精确的每应用 BatteryStats；排行是前台使用时长 + 当前电池功率的估算，不代表后台真实耗电。
- Shizuku 用于 CPU/GPU/系统温度等只读系统状态，不伪造精确耗电。
- 数据只在本机处理，不联网、不上传。
