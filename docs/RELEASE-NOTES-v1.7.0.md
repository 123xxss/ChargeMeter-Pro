# ChargeMeter Pro 1.7.0

## 新增

- **系统状态卡**：CPU 使用率/频率/核心数、可用内存、GPU 使用率、系统最高温度；详情页含存储剩余。
- **实时详情弹窗**：打开后每秒随主界面更新，不再是一次性快照。
- **三种界面风格**：Apple 极简（默认）、经典渐变、深色霓虹，功率卡/曲线同步切换。
- 长按功率卡复制当前功率。
- 曲线支持铺满、当前值/时间标注，新充电会话自动清空。

## 说明

- GPU、系统温度依赖标准 sysfs；部分机型系统不开放时显示 `--/系统未开放`，不会伪造数据。
- CPU 使用率来自 `/proc/stat`，内存来自系统 `MemoryInfo`，存储来自 `StatFs`。
