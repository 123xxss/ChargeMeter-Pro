## 4. 已知偏差与后续

- **锁屏卡片**：PRD 的“贴合原生充电动画位置”只有系统预装/厂商合作才能做到；本版用通知承载，属于权限模型下的明确降级，已在 README 和本表标注。
- **Shizuku**：PRD 要求“默认关闭、实验性、逐机型验证”。本版选择不接入，而不是交付未验证的高权限路径；标准 BatteryManager 路径与只读 sysfs 增强不受影响。
- **AOD**：无系统签名/白名单，隐藏入口。
- **逐机型实测**：目前只完成代码/单元测试与静态构建验证，vivo/OPPO/小米真机矩阵仍需按 PRD 8.4 验收。
- **30W 单电芯边界**：自动双电芯启发式在“双电芯品牌 + 7A 左右电流”时可能把 30W 单电芯误判为 2S；设置中可关闭/强制修正，详情页显示修正状态。
